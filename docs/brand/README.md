# Tinker's Belt brand pack

Logo pack from the designer (2026-11-17). Keep originals here; derive other sizes from these.

- `tinkers_belt_icon.*` - square app icon (dark tile). In-game icon is `media/icon.tga` (128px, made from the PNG).
- `tinkers_belt_icon_{64,128,256}.{png,tga}` - ready-made sizes.
- `tinkers_belt_logo.*` - wide banner with the name and tagline "A better way through Azeroth" (release page header).
- `tinkers_belt_transparent.*` - emblem without background.
- `tinkers_belt_minimap*` - round gear badge for the minimap button (32-256 px). In game: `media/minimap.tga` (the 64 px TGA), drawn without the default round border.

Fonts used in the logo: EB Garamond (titles), Lato (tagline/text). Colours: navy #050d18 to #163f46, teal #33dccc, brass/gold.
